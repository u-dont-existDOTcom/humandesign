## Controlling correction: direct self-report is not inference

The previous candidate used participant-facing **obviousness** as the reason not to record a Life Pattern. That is superseded.

Current controlling distinctions:

- **generic/high-base-rate vs person-specific** determines whether material is useful enough to become a Life Pattern;
- **direct participant-authored statement vs interviewer inference** determines whether another confirmation step is necessary.

A person-specific pattern can be obvious because the participant already knows it. If the participant already explicitly stated it, the interview should not repeat it back merely to ask whether it fits.

### Generic/high-base-rate material

May satisfy scientific coverage but is not promoted to a Life Pattern.

### Direct participant-authored person-specific pattern

The runtime may record it without a second confirmation only when it can mechanically bind the pattern to the participant's original source:

- accepted wording is an exact contiguous substring of one participant message;
- cited operative facts come from that same source turn;
- at least one cited fact is an attributed `reported_appraisal_or_belief`;
- the original participant source provenance is used as the participant-authority/adjudication evidence.

The v2 record still contains an accepted adjudication row because the accepted substrate requires participant-authoritative person-level patterns. No fabricated second decision event is added. If these direct-source checks fail, the runtime does not auto-record.

### Interviewer inference

Any added integration, comparison, causal/conditional relation, scope claim, or other proposition the participant did not explicitly state remains an ephemeral tentative synthesis and must be explicitly judged by the participant.

The obsolete **True, but too obvious — just move on** control and endpoint are removed.
