## Maya inclusion: decision distinction

Maya studies would be a **NEW independent source tradition**, not already absorbed into the Western/Jyotish/Chinese/Tibetan source counts. If the owner wishes to include it, source-first work should distinguish Mayan cultural/ritual calendars (Tzolk'in, Haab, Long Count), regionally distinct traditional daykeeper interpretations, securely dated original codices / scholarly editions, and **modern Dreamspell constructs**, which cannot silently be treated as ancient Maya originals. Predefine any input-calendar policy and measurable predictions before observing actual humans. The user's question about existing inclusion is not itself evidence a Maya model was previously tested or merged.
