# Full-survey recovery: what changed

The full scenario bank and existing evidence guide remain unchanged. This child branch adds an import-and-resume protocol and a self-contained packet builder. It does not change the astronomical model, deploy a survey, fit participants or claim the instrument is validated.

The observed class of problem is that an edited narrative interview can omit original route provenance and the conditions needed for some proposed mappings. The source of drift can be the interview, later editing, or both; without the original trace it is not established. Loading the right files at launch does not by itself prove final rendered questions and exported evidence retained those constraints.

The repair moves source/context checks to the actual mapping and next-question boundaries, preserves valid off-bank evidence, carries the full authorities with the packet, and distinguishes semantic gaps from export-format gaps. It requires neither an all-question checklist nor automatic rejection of paraphrases.

Private participant evidence is intentionally excluded from this public branch. Case-specific audit and delivery are separate private artifacts. Public fixtures are constructed, not redacted participant excerpts.

## Run

`python3 scripts/build_full_survey_resume_packet.py --output /path/outside/repo/full-survey-resume.md`

The generated packet contains the import protocol, original interview protocol, full bank and evidence guide. Attach the received response document privately alongside it. No birth information or chart output goes to the interview context.

## Limits

This repair makes a usable reversible continuation candidate. Its packaging tests prove source preservation and artifact usability only, not that a model interviewer will always follow it or that the survey predicts birth data. A participant trial and source-bound mapping review remain evidence still to obtain. Partial exploratory development remains allowed with explicit scope.

The public-method cross-family review and its disposition are preserved alongside the protocol. Edited wording and exposure safeguards were refined before delivery. The current source-only interpretation map still abstains on several domains; this repair neither creates those missing chart meanings nor makes them a questionnaire defect.
