# B02u source-fidelity lessons

- Five independent source-image first-reader windows exposed glyph errors and operator/actor losses. Independent readers' conflicting glyphs remain source uncertainty; not a reason to invent an aspect.
- Preserve printed errata apart from handwritten margin and original body (p3?7 locator is unresolved).
- A source reader's whole-PDF page request can exceed a phase stop placed at an original heading on that same page; hand off the excluded body as the next phase, do not double count or omit it.
- Source table images are preserved, but symbolic human names/physical descriptions are NOT validated predictions of actual people and not fully diplomatic numerical cell data.
- Existing UDA source-provenance and independent-evaluation separation already address these; no new portable universal rule claimed without external transfer justification.
