# Live pilot repair — repetition-value item — 2026-09-20

## Findings from live use

Two successive versions failed.

First:

> When the goal matters a lot to you, what would you usually do with those twenty minutes even if the practice feels repetitive?

This mainly measures whether strong motivation can sustain boring practice.

Second:

> When you repeat the same kind of practice over and over, what, if anything, do you get out of the repetition itself?

This incorrectly treats repetition as though it had one cross-activity meaning. The participant correctly pointed out that eating every day, exercise, language drills, music practice, and other repeated activities are functionally different.

## Correct design rule

`D22.repetition_value` is not admissible as a context-free trait from a generic “repetition” question.

Evidence must be tied to a **specific repeated activity** already understood by the participant. A single activity supports only that context unless multiple compatible contexts independently support a broader pattern.

Do not infer novelty seeking, discipline, boredom tolerance, persistence, or a global love/dislike of repetition from:
- continuing a boring activity because the goal matters;
- leaving working instructions unchanged;
- ordinary repeated necessities such as eating;
- one isolated practice context.

## Disposition for the current pilot

- Treat both failed repetition questions as design feedback, not participant evidence.
- Keep the earlier statement that persistence depends on how much the goal matters as a scoped motivation observation only.
- Leave `D22.repetition_value` unresolved for this participant for now.
- Do not ask another generic repetition question immediately.

## Future admissible route

Only if a concrete repeated practice later arises naturally and this distinction remains useful, ask about that **specific activity**, for example:

> When you repeat that exact exercise several times, is there anything you value in the repeating itself, or is it only a means to the result?

Interpretation boundaries:
- retain only the named activity and reported reward or lack of reward;
- do not generalize to other kinds of repetition without additional compatible evidence;
- “nothing; it is only a means to the result” is valid;
- multiple contexts may later justify a broader pattern, but one context does not.

## Pilot handling

Move on to another topic. Do not use the participant’s criticism or examples as trait evidence merely because they expose the design flaw.
