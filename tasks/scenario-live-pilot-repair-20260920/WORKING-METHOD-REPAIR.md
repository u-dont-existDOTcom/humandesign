# Live pilot repair — 2026-09-20

Source candidate: scenario-bank-v6.0-20260919

## Finding

The optional `WORKING-METHOD` item was not discriminating enough in live use. Asking what someone would do when instructions already work adequately mostly elicits the ordinary answer “keep using them,” and should not be treated as useful evidence about novelty seeking or as a meaningful method-change threshold.

The participant's live answer to that item is therefore **inadmissible as trait evidence**. `D04.change_threshold` remains unresolved for this participant unless a better contrast is asked later.

## Replacement wording

Use only if `D04.change_threshold` is still useful and unanswered:

> The calendar instructions work, but one step is noticeably slow and awkward every time you use it. What would you usually do?

Interpretation boundary:
- keeping the method, adapting it, asking for help, or abandoning it are all admissible;
- the answer is about the threshold for altering an inherited method under friction;
- do not interpret “leave working instructions alone” as low novelty-seeking;
- do not convert this one task into a global originality trait.

## Pilot handling

Do not re-ask this repair immediately merely to fill the field. Continue the interview and return to it only if the distinction remains useful later.
