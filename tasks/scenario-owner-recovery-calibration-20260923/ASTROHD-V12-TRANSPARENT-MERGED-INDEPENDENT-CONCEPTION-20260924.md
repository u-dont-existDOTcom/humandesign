## Problem

The behavior-only Human Design owner-training path is exhausted:

- the corrected observable scorer does not robustly recover the recorded date/time;
- categorical gate completion did not improve the target regression;
- the global-capacity owner-question strategy exhausted after two bounded fields;
- additional owner questions would now be materially similar optimization of a failing method.

## Candidate mechanism

Create a **new**, explicitly versioned transparent merged scorer rather than approximating the lost historical V1.1 implementation.

Reuse only components whose semantics survive exactly:

1. the frozen owner behavioral translation / cluster structure;
2. the historical per-side evidence algebra;
3. the cross-system merge rule:
   `max(HD, Western) + 0.25 × min(HD, Western)`;
4. the 6-bit rarity-information cap;
5. exact candidate-universe prevalence computed from the same declared search universe.

Replace the lost Western feature semantics with a new canonical registry where every predicate is explicit and machine-testable before any owner-case search result is opened.

- feature ID;
- astronomy quantity used;

- exact orb/threshold;
