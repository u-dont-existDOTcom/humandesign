# AstroHD V1.2 scientific-validity clarification — 2026-09-24

Status: **OWNER-CASE DEVELOPMENT FIT ONLY / NOT SCIENTIFIC VALIDATION**.

## Bottom line

The transparent Western-only V1.2 result is not a fraudulent post-score retune, but it is also not a scientifically validated predictive model.

V1.2 froze its Western predicate registry, astronomy conventions, direct-regression gate, and scoring implementation before opening the new V1.2 owner scores. No V1.2 orb, house rule, feature predicate, weight, location, or success threshold was changed after that reveal.

However, V1.2 deliberately reused the historical V1.1 behavioral cluster structure and Western feature salience/directness weights. That V1.1 model is explicitly labeled **post-selection descriptive**, is user-specific, and was developed after the owner case and target were already known. Therefore the owner case is not held out with respect to the mapping/weight family.

## What is mechanically objective in V1.2

- Swiss Ephemeris astronomy;
- fixed tropical zodiac convention;
- fixed Placidus houses;
- fixed Philadelphia location for this recovery task;
- explicit aspect/sign/house predicates;
- fixed 3-degree project-native major-aspect orb;
- empirical prevalence over the declared hourly century universe;
- deterministic score/rank calculation;
- predicates and regression success gate frozen before the V1.2 owner-score reveal.

These controls prevent a narrow form of cheating: changing V1.2 rules after seeing which rules make the known target win.

## What remains heuristic / unvalidated

The following are not empirically learned from independent participants:

1. **Behavioral cluster definitions.**
   The mapping from owner-reported behavior to constructs such as mystery inquiry, sanctuary/sensory home, strategic persuasion, etc. is hand-authored.

2. **Western feature selection for each cluster.**
   Examples include assigning Mercury-Pluto/Mercury-Jupiter/Neptune-12th to one behavioral cluster or Moon/Taurus/4th-house features to another. These are theory-driven mappings, not measured likelihoods.

3. **Salience/directness weights.**
   Values such as 1.0, 0.75, 0.55, 0.50, etc. are inherited from V1.1 and are not estimates learned from held-out data.

4. **Aggregation rule.**
   Taking the maximum matched Western pathway within a cluster rather than summing or fitting a probabilistic model is a design choice.

5. **Six-bit information cap.**
   The cap prevents rare features from dominating without limit, but its exact value is a heuristic design choice.

6. **Behavioral confidence values.**
   These are structured judgments from the owner interview/coding process, not calibrated empirical probabilities.

## Relationship to the V4.3 correction

V4.3 attempted to make weighting less arbitrary through structural prevalence/information weighting, but later diagnosis showed that it still rewarded unmeasured structural mechanism identity (for example Channel versus Gate alternatives) and therefore was not a valid behavioral likelihood model either.

V1.2 removes that specific behavior-only V4.3 failure by switching to a transparent Western feature family, but it **reuses V1.1's hand-authored feature-to-behavior mappings and salience/directness weights**. Therefore V1.2 should not be described as a scientific correction of V4.3. It is a cleaner, reproducible development model whose owner-case fit is interesting but post-selected.

## Correct scientific interpretation of the owner result

The statement supported by the current experiment is:

> Under a completely frozen, transparent reimplementation of the pre-existing V1.1-style Western feature/weight family, the owner case scores very near the top of the century universe and the recorded minute begins the best local-date plateau.

The following stronger statement is **not** supported:

> The V1.2 weights/mappings are scientifically correct, or Western astrology predicts birth time/personality.

The owner result cannot adjudicate those claims because the owner case helped motivate and historically shape the feature/weight family.

## What would make V1.2 scientifically testable

Freeze V1.2 exactly as it is now, including:
- all feature mappings;
- all salience/directness weights;
- behavioral coding rules;
- astronomy rules;
- prevalence universe;
- score aggregation;
- rank/search procedure.

Then evaluate fresh participants whose recorded birth times were not used to design any of those components. The recorded answers should remain hidden from the scorer/translator until each participant's behavioral evidence is frozen.

Primary evaluation should compare V1.2 against preregistered baselines such as:
- uniform/random rank expectation;
- date/time-only priors where applicable;
- an equal-weight version of the same feature family;
- a simpler Western-only feature-count baseline;
- the observable-only Human Design baseline.

Only repeated held-out performance materially above those baselines would justify treating the hand-authored V1.2 weights/mappings as more than a post-selected owner-case model.
