# Decoz current-name terminology correction

Status: **CONTROLLING INTERPRETIVE CORRECTION FOR CONTEMPLATED-NAME ARTIFACTS**

This note corrects an ambiguity in the prior Hale contemplated-name discussion.

## Correct rule

Under the Decoz convention used by this project:

1. The **full birth name remains the primary/core name profile**.
2. The **current name** is the name the person actually uses to introduce themself socially, including the last name.
3. A middle name is included in the current-name calculation **only if it is actually used in introductions**.
4. Current-name numbers are **Minor Expression, Minor Heart's Desire/Soul Urge, and Minor Personality**. They are lesser/minor influences relative to the full birth-name core.
5. A legal name change does not, by itself, establish the Decoz current-name calculation if the person does not actually use that full legal form socially.

## Hale application

Hale's birth-name core remains:

- Hatice Hale Baysan
- Expression 17/8
- Soul Urge 14/5
- Personality 21/3

If her legal name becomes **Hatice Hâle Denizden** but she normally introduces herself as **Hatice Denizden**, then the Decoz current/minor name is:

- Hatice Denizden
- Minor Expression 10/1
- Minor Soul Urge 7
- Minor Personality 12/3

The full-form **Hatice Hâle Denizden = 18/9, 13/4, 23/5** is relevant as a Decoz current-name calculation only if she actually uses the middle name when introducing herself.

If she continues introducing herself as **Hale Denizden**, then the current/minor calculation remains **17/8, 7, 19/1**.

## Supersession

This note supersedes any wording in the contemplated-name artifacts that could be read as making the legal/full name the primary or automatically operative current-name layer.

It does **not** change the arithmetic previously calculated for any spelling. It changes only which spelling is considered operative under the Decoz current-name rule.
