# V3 local pilot — survey information-quality lesson (privacy-safe)

**Evidence class:** one participant's private development response export. The exact personal answers, sensitive narrative and self-reported uncommon behavior descriptions are not part of this repository. Do not make cohort-wide or natal claims from this test.

## Audit results

- 25/25 question records supplied; none marked UI `unsure` or `skip`.
- Example selections per item: one chosen on 5/25, two on 4/25, three on 3/25, and **all four** on 13/25 (52%). Total example ticks: 74 across 25 questions (mean 2.96). These are nonexclusive examples, not 74 independent psychological observations.
- 8/25 questions also had respondent-authored `Other` commentary. The local pilot lists 3 unusual-behavior examples, below its voluntary 10–20 invitation, without implying anything about the person's chart rarity or identification difficulty.
- A few comments challenge item comprehensibility or information value; other free-text comments supply contextual conditions that selected options cannot express. Neither criticism nor selection count is a personality trait.

## What this teaches the instrument designer

1. **High checkbox coverage is not high information.** The respondent often endorsed all four plausible methods. Such options may describe sequential steps or domain-contingent choices rather than competing stable dispositions. Do not treat the selected labels as independent evidence for four traits; usually retain `conditional/unknown` until contexts or comparative tendencies are elicited.
2. **`Other` is a principal evidence channel.** Free text clarifies motives, relationships, intensity, fatigue, skill, opportunity and uncertainty. Preserve it verbatim and code it separately from checkbox labels; the original structured export needs import/edit/export to allow corrections.
3. **Genuine ambiguity is expected.** Broad first-step, problem-solving, danger-detection and social-impact questions can admit essentially every reasonable strategy because the context determines what is appropriate. The right follow-up identifies a comparable context, dominant contingency or counterexample, not demands a generalized winner.
4. **Instrument feedback is not trait evidence.** Comments suggesting a question was unclear or unhelpful should be sent to the versioned question-improvement lane, with source/route attribution. The volunteer's tendency to notice a poorly specified question is not evidence for any chart feature.
5. **Distinctive behavior content may improve discovery, not validated prediction.** The voluntary inventory supplies richer action/context/motive data across different personal domains. Self-reported unusualness is not established population rarity; item count is confounded by recall, modesty, language, opportunity and willingness to disclose private facts. Never infer ease of DOB/time identification from count alone.
6. **No chart scoring.** This one owner's already-known case is development evidence. A future independent test must compare open-only versus example-supported format, and inventory-added versus baseline survey, using the same unseen people and a preregistered chart feature/decoder/scoring model.

## Low-cost reversible repair applied to the local pilot

- Add/Edit/Cancel/Remove each unusual item, including context, comparison group and motivation, with saved order preserved.
- Import previously exported V3 JSON so a reopened HTML page can restore completed answers; re-export edited JSON. Do not silently replace an in-tab dataset.
- Confirm destructive Clear and Reset actions. No remote storage, network, or auto-save; the user must export changes.
- When all four examples are checked, present an **optional** contextual note, not a forced trait choice.

## Follow-up experimental protocol (not admitted to live scoring)

Run a cognitive interview sample unfamiliar with the questionnaire and compare answerability, time, selected-option entropy, rate of four-way selections, self-described conditions, prompted versus spontaneous inventories, comprehension and corrected answers. A small `n=1` trial can expose defects; it cannot estimate population distributions or incremental natal predictiveness.
