# Reopen, edit and re-export the local V3 Life Patterns pilot

The owner asked for an Edit button on the unusual-behavior list and asked what the uploaded responses teach us. Both are addressed without changing live participants, the frozen source or the natal scorer.

Implemented: A visible Edit button for every saved unusual behavior, with all original fields loaded; Save changes and Cancel editing; Remove with confirmation; Clear and Reset with confirmation; import of compatible exported V3 JSON with validation, overwrite confirmation and previous question answers restored; re-export with unchanged schema. The interface does not use network or storage. The original local file remains untouched, and the prior generated HTML is preserved as a backup.

QA: synthetic browser fixture proving import 25 answers, 3 unusual behaviors, edit/cancel, reimport and exact JSON export preserving all untouched data. Private readback of the owner's exact export was performed on the authorized local machine with no private text printed or committed. The resulting private respondent interpretation is separate from the public, aggregate-only RESPONSE-QUALITY-LESSON.md.

Observed instrument-quality signal (n=1): 13/25 question sets had all four example responses selected; 8/25 had additional free text; 3 volunteered unusual behaviors. These are neither validated psychometric estimates nor chart-matching evidence. The local UI now offers an optional explanatory prompt when all four are checked, without forcing a score direction.

No update to the active GPT/Railway/question bank. Future birth-time inference would require new blinded respondents and preregistered source-to-target mapping.
