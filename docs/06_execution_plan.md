# 06 — Execution Plan

## Phase 0 — Repository bootstrap
Deliver:
- Python package scaffold
- CLI
- configuration system
- schemas
- logging
- pytest
- reproducible environment
- CI

## Phase 1 — Exact chart engine
Implement and test:
- IANA historical timezone conversion
- UTC normalization
- astronomical longitudes
- exact 88° solar-arc Design root
- Rave Mandala gate/line mapping
- channels/centers
- Type/Strategy
- Authority
- Profile
- Definition
- exact boundary event enumeration
- stable interval construction

Do not proceed to global claims until independent engine checks pass.

## Phase 2 — Compile existing symbolic model
Convert existing V4/V3.2 constructs into typed machine-readable mappings.
Produce unresolved-mapping report.
No search optimization yet.

## Phase 3 — Synthetic oracle benchmark
Generate at least:
- 1,000 known-month oracle cases;
- 1,000 known-year oracle cases;
- 1,000 known-date time cases.

Goal: near-perfect recovery when the decoder and generator share the same deterministic model, modulo structurally indistinguishable states.

Failures are engineering bugs or information-identifiability limits to investigate.

## Phase 4 — Synthetic noise benchmark
Generate low/medium/adversarial sets.
Measure degradation and identify weak question clusters.

## Phase 5 — Adaptive questionnaire optimization
Optimize on synthetic development cases.
Freeze on untouched synthetic validation cases.

## Phase 6 — Human development mode
Build import schema for human questionnaire + verified birth data.
Fit theory, empirical, and hybrid models.
Support repeated model revisions.

## Phase 7 — Human internal validation
Nested CV / validation set.
Do not use final untouched cohort.

## Phase 8 — Prospective human blind test
Freeze:
- questionnaire,
- model,
- mapping version,
- question selector,
- candidate universe rule,
- stopping rule,
- metrics.

Then run untouched participants.

## Phase 9 — Minute rectification
Use participants with documented minute-level records.
Near-neighbor same-day candidate states.

## Phase 10 — Global search
Only after previous stages demonstrate adequate discrimination and engine stability.

## Phase 11 — Practical Authority experiment
Separate project endpoint. Do not conflate birth-chart recovery with whether Strategy/Authority improves decisions.
