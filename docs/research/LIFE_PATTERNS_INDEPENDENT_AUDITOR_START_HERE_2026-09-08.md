## Episodes and repeated recurrence are different evidence forms

### Bounded episode

An episode supports what happened in that bounded instance. It can clarify sequence, context, opportunity, feasibility, consequences, or a stated explanation.

A concrete example does **not** automatically strengthen a broader frequency claim simply because it confirms the same pattern.

### Repeated-series / generalized behavioral recurrence

A direct behavioral self-report such as:

- “I always X”;
- “I usually X”;
- “I often X”;
- “sometimes I X”;
- “this happened repeatedly”

is evidence that the narrator **reports the behavior as recurring at that strength/scope** when the exact source supports it.

It is not zero evidence merely because it is not a concrete episode. It is also not automatically external verification of the true opportunity-level frequency.

A confirming anecdote selected after the recurrence claim is not an independent frequency observation and must not be counted as extra frequency support.

There is **no requirement to invent a minimum occurrence count** for generalized recurrence language. Record a count/rate only when the exact source itself provides a defensible bounded count or rate.

Keep recurrence strength separate from exception status. The word “always” alone does not prove that the participant explicitly denied all exceptions. Preserve reported exceptions and boundary conditions when the exact source supplies them.

## Observed responses

When you choose **Observed**, select only values allowed by the interface and cite exact supporting source segment(s).

If more than one value is genuinely supported, use the permitted relation:

- single;
- ordered sequence;
- unordered multiple.

Do not choose multiple values merely to hedge uncertainty. Use Insufficient when the evidence cannot resolve the code.

### Non-action values

If a selected value represents substantive non-action, all four prerequisites must be established by the supplied evidence:

1. awareness;
2. meaningful opportunity/window;
3. reasonable feasibility;
4. established non-occurrence during that window.

Silence or non-mention is not proof of non-action. If any required element is unclear, do not force the non-action code.

### Other Specified

If the frozen Other-Specified value is used, provide the concrete description required by the interface and ground it in the supplied exact source.

## Important evidence rules

- Exact source segments are primary evidence.
- Transfer summaries are orientation only.
- Preserve counterevidence and exceptions.
- Specificity is not evidential independence: a vivid example can clarify a claim without independently strengthening its frequency.
- Sequence is not the same as mixedness; preserve an established within-episode sequence.
- Temporal order does not prove causation. Record influence only when the narrator explicitly states it under the supplied rules.
- A behavioral recurrence statement such as “I always checked the door” is different from a trait interpretation such as “I am always cautious.”
- Silence/non-mention is normally insufficient evidence, not proof of non-action.
- Do not optimize for agreement with what you imagine another coder would choose.
