# Exact-Pair State-History Source Ladder V3 — Final Summary

Status: **frozen three-rung source ladder exhausted below the 30-pair sufficiency gate; do not fit the planned dissolution/reunion semi-Markov model on this 64-pair universe.**

## Fixed universe and gate

The source ladder was restricted to the same 64 exact-time romantic pairs from the exact-pair V3 timing development study. The sufficiency threshold was fixed before the source-ladder counts were known:

- fewer than 30 unique exact-time pairs with a usable nonfatal dissolution/reunion endpoint -> STOP;
- at least 30 -> proceed only to writing and freezing a separate semi-Markov model specification, not immediate fitting.

No astrology or Human Design feature was used during state-history recovery or source adjudication.

### V3 Rung 1 — ADB Biography prose

The first automated same-sentence parser reported an optimistic 25, but source-provenance audit exposed unambiguous parser defects, including timezone `MET` being read as the verb `met`, unrelated dates being attached to generic marriage terms, and multi-partner sentences being misattributed.

The Biography-only additions were therefore quarantined rather than used to satisfy the gate. This was a source/parser quality correction made without astrology/HD information. The clean baseline remained **23**.

### V3 Rung 3 — exact linked Wikidata P26/P451 statements

Identity was restricted to Wikidata QIDs inherited from the exact ADB -> ADB-linked English-Wikipedia chain. No Wikidata name search was permitted.

Only exact opposite-partner statements under:

- P26 spouse;
- P451 unmarried partner;

were inspected, with timing/end semantics restricted to P580/P582/P1534.

Observed structured end-cause QIDs on exact pair statements resolved to only:

- `divorce`;
- `death`;
- `death of subject`;
- `death of subject's spouse`.

There were 88 exact pair P26/P451 statements across the linked identities. Under the frozen rule requiring a usable P582 end time plus a P1534 English label in a nonfatal lexical family for a *new* endpoint:

- newly endpoint-bearing pairs: **0**;
- final clean total: **28/64**.

## Frozen stop/go result

**28 < 30.**

Therefore the source ladder is exhausted for this fixed 64-pair public-figure universe and the planned dissolution/reunion semi-Markov model must **not** be fit from it.

The threshold must not be lowered from 30 after observing 28.

## Scientific interpretation

This is a **data-sufficiency failure**, not evidence for or against astrology or Human Design.

The exact-time timing V3 study itself remained a negative development result under its frozen predictive threshold. The state-history work here was intended only to make a stronger longitudinal transition test possible; it did not evaluate astrological features.

The most defensible next development step is to freeze a broader ADB exact-time romantic-pair universe *before enumerating its endpoint counts*. The original 64-pair universe was artificially narrow because membership required a pre-existing strictly partner-linked C-sample transition event. A broader universe can instead include every structured romantic ADB link where both partners ultimately resolve to A/AA exact-time records, then apply the already-audited structured state-history rules without requiring an event as an entry criterion.

That broader ADB sample would still be development data, not independent validation. Any relationship-timing hypothesis learned from it would still require a genuinely independent couple dataset for confirmation.
