# Astrology source acquisition and reading order — V2

5 October 2026 · This is a source-acquisition plan, not a completed source audit or a claim that the methods are empirically valid.

## Start with the existing four authorities

Finish the original corpus before expanding. The priority is to recover missing conditions, exceptions and synthesis rules—not to accumulate impressive-sounding techniques after seeing outcomes. Three of these four works are now downloaded locally. Robbins’s complete four-book text is verified online but its local retrieval remains unresolved.

## What these sources add without double-counting

| Audit gap | Main sources | Boundary |
|---|---|---|
| Natal judgement beyond dignity tables | Lilly Book III; Ptolemy III–IV; Valens | Do not infer a whole natal system from a selected strength table. |
| Conditions, exceptions, reception and configurations | Dykes’s Introductions; Rhetorius; Paulus | Separate original statements from modern editor explanations. |
| Lots and time-lord methods | Valens; Paulus; Dorotheus | Freeze formula, sect reversal, epoch and subperiod conventions. |
| Annual/monthly predictive hierarchy | Abu Ma’shar PN IV; Lilly III | PN III is a partial witness, not an adequate substitute for PN IV. |
| Jyotish | Phaladeepika; BPHS both volumes; Brihat Jataka | Keep recension, ayanamsa, nodes, aspects, vargas and dasha conventions explicit. |
| Tājika annual astrology | Hāyanaratna/Gansten | Separate module; not silently merged into Parāśari doctrine. |
| Primary directions implementation | Primary texts plus Gansten | The modern guide explains conventions; it is not an independent ancient confirmation. |
| Modern transits/progressions | Hand; Leo | Separate source families, not attributed to Lilly or Valens. |

Do not substitute an excerpt, a missing-volume set, an unrelated similarly titled book, a newer reprint with altered content, or an undocumented translation and mark the target complete.

## Stop rule for acquisition

Acquisition is complete per work only after identity, edition, language, contents/section span and file readability are checked. A parsed PDF is not a complete reading. The next stage inventories every source section and extracts conditional rules with exceptions before any new person-specific application. Full source-tradition completeness remains open.
