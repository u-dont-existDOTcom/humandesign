# First forward-blind DEVELOPMENT pilot

Purpose: debug the prospective workflow before any evidential cohort.

## Size

5–10 participants.

## Inclusion preference

- documented exact birth time;
- birthplace known;
- little or no prior Human Design knowledge;
- adult and able to provide concrete behavioral examples;
- not already used to tune the frozen questionnaire/model where avoidable.

## Procedure

1. Assign pseudonymous ID.
2. Record birth data, time-source quality, stated uncertainty, HD familiarity.
3. Privately calculate chart with verified SWIEPH.
4. Freeze intake/chart/model/question/option-order/decoy hashes before scored answers.
5. Administer concealed-direction questionnaire.
6. Freeze responses.
7. Score direct predictions and matched decoys.
8. Reveal chart only after evaluation freeze.
9. Record failures, ambiguous questions, leakage, and participant feedback.
10. Any changes create a new model/question-bank version; pilot participants remain DEVELOPMENT forever.

## Pilot success criteria

Engineering/UX only:

- no chart/answer-direction leakage before response freeze;
- complete audit package produced automatically;
- uncertain answers remain unscored rather than coerced;
- matched decoy generation deterministic and reproducible;
- participant can verify prediction seal existed before answers;
- failures and poor matches are retained.

Do not define a minimum predictive accuracy for the DEVELOPMENT pilot.
