## Additional methodological lesson

When an event label is coarse (for example only a year) and multiple major events occur in that same interval:
- a high model score inside the interval is not attributable to the target event;
- treat the interval as confounded;
- recover narrower chronology before claiming localization;
- do not select whichever event best matches the peak after inspection.
