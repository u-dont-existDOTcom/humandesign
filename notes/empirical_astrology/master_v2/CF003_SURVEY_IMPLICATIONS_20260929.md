# CF-003 and survey implications\n\nDate: 2026-09-29\n\n## Current decision\n\nDo not change the frozen same-hospital primary questionnaire to make room for CF-003.\n\nThe current prospective primary is theory-neutral TN-001 and uses the fixed 50-item IPIP Big-Five factor-marker sample. CF-003 was developed for biography/public-prominence dominant-planet matching, not for the IPIP-50 personality-distance endpoint. Adding CF-003 questions to the primary survey now would create an outcome transport that has not been justified by the literature or approved by Pro.\n\n## What can change now\n\nKeep the existing required pre-questionnaire exposure fields: prior natal-chart reading, own-sign trait knowledge, HD interpretation exposure, astrology belief 0-4, ability to name own Sun sign, and recruitment source.\n\nNo astrology label, chart, predicted direction, pair assignment, gap category, or CF-003 score should be shown before response freeze.\n\n## If CF-003 is reopened later\n\nA clean prospective CF-003 test should be a separate secondary study/module, not a modification of the TN-001 primary endpoint.\n\nThe key requirement is a chart-independent target. The historical CF-003 biographical target is generated partly from chart-conditioned word portraits, so copying that target into a new survey would preserve the circularity concern.\n\nA future Pro-approved CF-003 module would need:\n\n1. Independent target measurement: collect self-report and/or biography information before chart scoring, use a frozen chart-blind coding procedure, and freeze vocabulary/model/prompts/tie rules before outcomes.\n2. Separate prediction freeze: calculate the seven-factor CF-003 predictor from birth data only and freeze per-person planet scores/ranks before opening target responses.\n3. Correct null: reassign complete target profiles under a justified exchangeability design and recompute every target stage affected by reassignment; do not shuffle only finished target labels.\n4. Independent replication: develop any target mapping on development participants and confirm on a fresh untouched cohort.\n\n## Practical survey consequence\n\nFor the upcoming same-hospital study, keep the frozen IPIP-50 primary measure plus the existing astrology/HD exposure and sign-knowledge fields and required hospital-frame provenance/covariates.\n\nDo not add CF-003-specific questions yet.\n\nIf the authors provide the unpublished CF-003 package and Pro later authorizes a prospective CF-003 test, add a separately versioned target module rather than altering the primary IPIP-50 scoring contract.\n
