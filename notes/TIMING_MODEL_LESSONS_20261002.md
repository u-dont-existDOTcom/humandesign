# Timing-model lessons — 2026-10-02

## Durable lessons

1. **Hits and false peaks are symmetric evidence.**
   A timing model is not improved merely because a known event receives a strong score. Strong non-event periods must be penalized and preserved as hard negatives.

2. **Occurrence, morphology and impact are separate targets.**
   Keep distinct:
   - whether an event occurred;
   - whether it was sudden/prolonged, violent/nonviolent, acute/chronic;
   - whether it was life-changing or comparatively low-impact.
   A component that helps one sudden/high-impact case does not establish that suddenness or impact caused the success.

3. **Morphology-specific features require ablation.**
   A shock/rupture modifier is a hypothesis. Compare neutral versus morphology-specific variants on later cases. Do not transfer it automatically to a prolonged event of the same broad class.

4. **Post-reveal repair is development only.**
   A repaired model must improve the true-event versus motivating-false-peak margin, but passing that regression does not validate it.

5. **Use causal windows.**
   Candidate-date scores may use only information available up to that date. Centered windows that borrow post-event contacts are descriptive only and cannot support prospective claims.

6. **Control mechanical dependencies.**
   A physical contact may satisfy multiple logical gates but receives score once. Collapse angle-axis duplicates and mathematically dependent constructions.

7. **Separate event endpoints.**
   Relationship onset, chronic pressure, acute escalation, pregnancy/family state, exact birth timing, parental event timing and subjective turning points are not interchangeable.

8. **State/window detection is not exact-event timing.**
   Slow transits, progressions and solar arcs may identify a broad state. Exact-event localization requires a separately frozen rule and must not be credited merely because the event falls somewhere inside a broad state.

9. **Background is not automatically negative.**
   When history is incomplete, unlabeled periods are background/unknown. Only periods reliably known not to contain the endpoint become hard negatives.

10. **Learned models stay frozen prospectively.**
    Once a model is trained and future predictions are written, keep them unchanged until enough outcomes accumulate for a separately versioned retraining.

11. **Store failed candidates.**
    Rejected hand-weighted models and false peaks remain part of the evidence history; do not delete them after a better model is found.

12. **Cross-person validation is the next evidential boundary.**
    Owner cases are development data once revealed. Transfer requires frozen testing on other people with positive dates and explicit control periods.


## New evidence from maternal-loss blind test

The maternal-loss blind test (actual date 2022-09-19) missed under both frozen variants:
- neutral model ranked the actual date only around the 66th percentile of all daily candidates;
- chronic-persistence model improved it only to about the 74th percentile;
- both variants instead selected late June 2025.

This strengthens two lessons:
- morphology-specific success in the father's post-reveal V4 cannot be generalized from one case;
- the presence of several symbolically plausible contacts near a true event is not enough if the same model produces stronger false peaks elsewhere.

The correct next evidential step is not further owner-specific repair. It is cross-person testing of:
1. a morphology-neutral parental-event model;
2. a sudden/acute modifier;
3. a chronic/prolonged modifier;
with the same false-positive metrics and person-level holdout.
