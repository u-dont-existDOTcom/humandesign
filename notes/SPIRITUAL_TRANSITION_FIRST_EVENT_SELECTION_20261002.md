# Spiritual-transition first-event selection correction

Date: 2026-10-02
Status: added before owner reveal.

The task asks for the **first** ego-death and **first** stream-entry/nibbana event. Ranking the single strongest lifetime peak would answer a different question.

Selection rule:
1. compute the already-frozen daily score across the full 1995-2026 scan;
2. define Tier A as >=99th percentile of that endpoint's full daily score distribution;
3. group Tier-A days into clusters separated by >30 days;
4. for a "first" endpoint, the committed primary guess is the **earliest Tier-A cluster**;
5. report the highest-scoring day inside that earliest cluster as the nominal peak;
6. the next chronological Tier-A cluster is the runner-up.

If no Tier-A cluster exists, fall back to the 95th percentile, but that fallback was not needed here.

This correction changes event-selection semantics only. No astrology feature, orb, weight, or contact score was altered after inspecting the scan.
